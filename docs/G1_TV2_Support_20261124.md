## Cơ chế và API

`POST /api/v1/moderation/groups/{groupId}/versions/{groupVersionId}/publish-batch`
với session ACTIVE + ADMIN + `question:publish` (fresh RBAC dưới shared lock):

```json
{
  "expectedRevision": 2,
  "expectedPublishedVersionId": null,
  "members": [{
    "questionId": "uuid", "questionVersionId": "uuid",
    "expectedRevision": 2, "expectedPublishedVersionId": null, "order": 1
  }]
}
```

Pointer null phải hiện diện tường minh ở lần publish đầu. Không nhận query params.
1–200 members là giới hạn request kỹ thuật, không xác định số câu chuẩn của Part.
ID và order không trùng; order liên tiếp 1..N. Chọn version APPROVED của đúng parent,
pin chính xác groupVersionId, order đã lưu; không đổi thứ tự lúc publish.

Thứ tự nghiệp vụ nhập tại authoring question bằng `groupQuestionOrder` (dương hoặc
null), đọc lại trên management version DTO; lưu vào cột V23 có sẵn. Edit DRAFT ghi
contributor/revision hiện hành, edit published tạo DRAFT mới và giữ order cũ nếu
không chỉ rõ. Không backfill NULL theo UUID/timestamp, không sửa approved/published
để chèn order sau review. Group order NULL cần trả DRAFT/sửa/gửi duyệt lại.

Batch khóa RBAC → group parent/version → các question parent/version → toàn bộ
media/grant theo thứ tự UUID text. Cả group và các câu đều phải đủ evidence vòng,
revision approval khớp, sourceVersionId bằng current pointer, không ARCHIVED,
publisher không là contributor của bất kỳ thành phần nào. Một Part 3/4/6/7 chung;
choice key hợp lệ; mọi current non-archived member phải được thay thế tường minh.
Không tự clone/repin/drop/archive hoặc publish thêm câu ngoài batch.

M1 owner/grant chưa revoked + read/type/visibility kiểm cho union media của cả
batch; không dùng manage:any hay ADMIN làm bypass. Đổi tất cả pointers/status,
published revision, decision và audit cùng transaction. Lỗi audit/media/any member
rollback toàn bộ. Race hai publisher chỉ một thành công; replay stale trả 409.
Versions và attempt đã pin trước đó giữ nguyên.

Publish từng câu thuộc nhóm hoặc endpoint publish đơn của group vẫn chặn
`GROUP_PUBLICATION_NOT_AVAILABLE`; phải dùng batch. UI moderation hiện tại tiếp tục
submit/approve từng version, thông báo chưa có công cụ chọn batch trên màn hình.
Không nhận backend API batch là UI authoring→publish end-to-end đã hoàn tất.

Mã lỗi: 400 `VALIDATION_ERROR`, 401/403 auth/RBAC; 404 `MODERATION_NOT_FOUND`; 409
`STALE_REVISION`, `SOURCE_VERSION_CHANGED`, `MODERATION_STATE_CONFLICT`,
`CONTRIBUTOR_EVIDENCE_REQUIRED`, `SELF_REVIEW_FORBIDDEN`,
`APPROVAL_REVISION_MISMATCH`, `GROUP_MEMBER_MISMATCH`,
`GROUP_MEMBER_SNAPSHOT_MISMATCH`, `GROUP_MEMBERS_REQUIRED`, `GROUP_PART_MISMATCH`,
`PUBLICATION_MEDIA_UNAVAILABLE`, `QUESTION_INCOMPLETE`, `PARENT_ARCHIVED`;
audit/database error trả 503 `MODERATION_UNAVAILABLE` và rollback.
